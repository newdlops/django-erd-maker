# Extension icon

`icon.png` is the Marketplace and VS Code extension icon. It uses the existing
diagram palette: navy `#081018`, mint `#6dd0b0`, amber `#ffbf69`, and pale field
marks `#e7f2f0`. Three table cards and two straight connections communicate the
product's purpose without text or third-party logos.

Created on 2026-09-16 using OpenAI's image generation tool, then refined with its
image editing tool. The included PNG is the source asset; no vector master is
claimed. It follows this project's license to the extent copyright applies.
It is not an official Django or Visual Studio Code logo.

Generation direction: a square app icon with one larger amber table card on the
left and two mint table cards on the right, joined by two straight lines; two
pale field marks per card; a navy background; no text, letters, shadows, glow,
or surrounding mockup. Refinement removed the first result's unwanted holes and
marks and retained the same composition on an opaque background.

Acceptance: a square PNG at least 128 pixels wide, distinguishable table shapes
and connections at small icon sizes, and a palette consistent with the diagram.
