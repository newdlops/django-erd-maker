# 0.0.1074 무캐시 재분석 측정

2026-10-05 현재 로컬 프로젝트에서 소스 탐색, Rust 분석, OGDF 배치,
최종 화면 기준 검증, HTML 문서 생성까지 측정했습니다. 모델·배치·학습
미리보기 결과 캐시는 읽지 않았으며, 요청마다 소스를 다시 분석했습니다.
실행 파일과 컴파일 산출물은 설치된 도구로 사용했습니다.

0.0.1074는 0.0.1073과 비교해 개요 visualCross가 33개, 개별이 32개
감소했습니다. 배치 BBOX와 간격 위반도 줄었고, 무캐시 재분석은 2분
이내입니다. 최대 RSS는 123.9 MiB로 128 MiB 상한에 가깝습니다.
개요 1,719개 표시 경로와 기존 Leaf cards 6개, 개별 1,732개 직선 경로를
각각 실제 렌더 모델로 감사했습니다. 0.0.1074 개요 점수는 선 교차 2,290개,
카드 충돌 619개, 묶음 충돌 3개를 합산합니다. 개별 점수는 선 교차
2,299개와 카드 충돌 623개입니다. 노드·묶음 카드 겹침은 모두 0입니다.

소스에서 추출한 모델 1,251개 중 ID 충돌 4개는 기존 정규화 규칙으로
처리했습니다. 구조 관계 3,307개는 방향별 동일 연결을 합쳐 1,744개로
네이티브 배치기에 전달했으며, 자기 관계 12개를 제외한 1,732개 경로가 모두
결과에 포함됐습니다. 관계의 의미와 원래 필드 정보는 유지합니다.

측정은 Apple Silicon macOS의 단일 작업자에서 실행했습니다. 외부
메모리 감시기는 분석 호스트와 네이티브 작업자를 합산하여 128 MiB를
상한으로 적용했습니다. 실행 우선순위는 nice +10, 작업 스레드는
1개였습니다. 이 수치는 VS Code 전체 프로세스 메모리를 의미하지
않습니다. 컴파일 단계에만 최대 512 MiB를 허용합니다.

최적화 모드는 새 그래프의 클러스터 배치에서 시작해 실제 카드 크기로
이동·교환 후보를 평가합니다. 클러스터 knot 교환은 45,000개 후보 평가와
기존 5초 벽시계 안전 제한을 함께 적용합니다. 위치 탐색의 전체 예산은 최대 40초이자
작업자 제한 시간의 절반 이내입니다. 기본값에서는 앞의 약 30초를 탐욕
탐색에 사용하고, 같은 예산 안에서 최대 10초를 확률적 탐색에 예약합니다.
잠시 점수가 나빠지는 이동을 허용하되, 요청 안에서 가장 좋았던 전체
좌표를 복원한 뒤 최종 장면을 다시 감사합니다. 카드 겹침이나 잘못된
경로가 생기는 이동은 거부합니다. 명시적 0 예산은 두 탐색을 모두 끕니다.

각 후보는 변화한 직선과 이동한 카드가 가로막는 다른 직선을 함께
계산합니다. 공간 인덱스와 최선 후보는 해당 요청에만 존재하며, 다음
분석에 재사용하지 않습니다. 노드·관계 누락, ID 중복, 점이 2개가 아닌
경로는 후보 채택 전에 거부하며, 초기 결과에서 고립된 모델이 누락된
경우도 거부합니다. 부분적으로 겹치는 평행 직선과 허용 오차 안의
공선 경로를 전체·증분 점수에서 같은 방식으로 거부합니다.

독립 네이티브 감사에서 1,732개 비자기 관계가 모두 확인됐으며, 퇴화
경로, 부분 선 겹침, 인접 관계 교차, 자기 교차, 불변식 위반은 모두
0이었습니다. 0.0.1074 감사의 선 교차는 2,299개, 네이티브 카드 충돌은
617개이며, 실제 렌더 개별 화면은 카드 충돌 623개로 계산합니다.
이전 JS·네이티브 통합 테스트 61개가 통과했으며, 이번 knot 후보 상한
회귀 테스트도 통과했습니다.

개요 교차 ≤200, 개별 교차 <500 목표는 아직 충족하지 못했습니다.
노드 겹침은 0이지만, 개요 간격 위반 304개와 BBOX 6.714B도 기존 품질
기준에 미달합니다. 최적화 결과는 `quality-degraded`로 표시합니다.
이전 릴리스의 285 / 1,963 수치는 다른 그래프의 저장된 학습 미리보기이며,
이번 무캐시 재분석의 성과로 계산하지 않습니다.

0.0.1073 설치 검증 때 별도 화면 검증에서는 실제 Electron/Chromium
WebGPU HTML을 열고 캡처한 화면을 확인했습니다. 로드부터 `webview.ready`까지
약 0.25초였으며, 1280×800,
768×1024, 390×844에서 문서 넘침과 GPU 경고가 없었습니다. 모델 선택과
Leaf cards 전환을 실행했고, 전환 후 1,247개 모델과 1,732개 경로가
유지됐습니다. 페이지 오류는 없었으며 프레임 시간 경고는 기록됐습니다. 이는 위 재분석
측정과 별도로 확인한 것으로, 0.0.1074에서 화면 크기별 브라우저 스크린샷을
다시 확인한 것은 아닙니다. 0.0.1074의 두 실제 렌더 장면은 생성된 HTML에서
별도로 감사했습니다.

0.0.1074 기본 상한 측정은 전체 소스 실행 한 번의 결과입니다. 동일 입력
반복에서는 네이티브 배치 결과가 달라져 점수 변동이 남습니다. 다른 프로젝트의
크기·연결 밀도·기기 부하에 따른 시간 차이는 남아 있습니다. 새 요청의
전체 분석에는 110초, 배치에는 최대 90초의 공유 마감 시간을 적용하여
무제한 분석이 UI 표시를 막지 않도록 했습니다.
